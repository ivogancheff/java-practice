# java-selenium-automation

UI test automation practice with Java, Selenium WebDriver and TestNG,
using the practice pages on [LetCode](https://letcode.in).

## Tech stack
- Java
- Selenium WebDriver 4
- TestNG 7
- Maven

## How to run the tests
1. Install Java 17+ and Google Chrome.
2. Clone this repository and open it in IntelliJ IDEA.
3. Right-click `src/test/java` and choose Run 'All Tests'.

## Components automated
1. Week - 1
2. Component - Input
3. Page - https://letcode.in/edit
